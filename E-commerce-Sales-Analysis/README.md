# E-commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data to identify sales trends and gain meaningful business insights.

## Tools Used
- Microsoft Excel
- Power BI

## Work Done
- Cleaned and prepared the dataset using Excel.
- Checked for missing and duplicate values.
- Organized the data for analysis.
- Created interactive visualizations using Power BI.
- Analyzed sales performance through dashboards.

## Key Skills
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development
